# Historical routing container

This directory preserves the original container/deployment materials. The restored free demo uses the **repository-root `Dockerfile`**, `deployment/` data/build scripts and the bounded Node gateway in `application/`.

Use the [current deployment guide](../DEPLOYMENT.md), [data provenance and licensing](../deployment/DATA.md) and [root README](../README.md). Do not deploy the old Heroku/Compose configuration to reproduce the current public demo. Historical files remain for context; their presence does not mean an old host is still active or has stopped billing.
